# 量力

反自律养成 · 单文件 H5

不靠羞耻和惩罚驱动习惯,靠宽容和陪伴:猫伙伴陪你管理负荷,把念头种成内心花园,今日契约认领一件真心想做的"小事",做到就有分量。

## 怎么跑

单文件应用,直接打开 `index.html` 即可(纯前端,数据存 localStorage,可导入/导出备份)。也可部署为 PWA(已带 manifest + sw.js)。

## 结构

| 区块 | 说明 |
|---|---|
| 今日 | 猫伙伴 + 负荷状态 + 今日计划 + **契约卡**(认领今日一件小事)+ **宽恕令牌**(护住一天,漏做不掉连击) |
| 成长池 | 念头存放/冷却/归档 + **内心花园**(念头长成植物)+ **圣物商店**(成长点兑换宽恕令牌/灌溉露珠等) |
| 专注 | 番茄钟(可绑定计划) |
| 我的 | 猫 + 数据看板 + 设置 + 备份(支持导入「学苗」导出的学习记录 JSON) |
